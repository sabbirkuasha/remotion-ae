# Features fixture

Test project for remotion-ae: together with remo's `examples/rickshaw` it uses every feature a remo
`timeline.json` can express.

The images were made by the project author with AI image generators (Codex and Gemini).
`clips/street.mp4` is a still-image clip made from `01_street.jpg` with ffmpeg, with a 660 Hz tone added as its
own sound; the audio files are test tones generated with ffmpeg.
